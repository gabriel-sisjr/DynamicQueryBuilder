Defines a builder for constructing SQL queries.

public interface IQueryBuilder

Remarks

Column names, joined tables, join conditions, operator strings and values are inserted into the generated SQL verbatim, and so is the table of FromTable(string), except that it is converted to upper case. Nothing is parameterized, quoted or escaped, and nothing is checked against the metadata given to Setup(Dictionary<string, List<string>>) except the table set by FromTable(string). Do not pass untrusted input to these methods: it allows SQL injection. String literals must carry their own quotes, for example "'Alice'".

Filters are emitted in the order they were added, joined by AND or OR without parentheses, so the database's operator precedence applies. The AND or OR of the first filter is not emitted.

Each clause method changes this instance and returns it. Columns, joins, filters, GROUP BY and ORDER BY items are only appended, and there is no way to remove them or reset the builder; FromTable(string) and SetLimit(int) replace their value. The generate methods do not change the instance.

Join(JoinOperators, string, string)

Adds a JOIN clause to the query, emitted as {join type} {table} ON {condition}.

IQueryBuilder Join(JoinOperators type, string table, string condition)

Parameters

type JoinOperators

The type of join represented by a JoinOperators enum.

table string

The table to join, emitted verbatim.

condition string

The condition on which to join, emitted verbatim.

Returns

IQueryBuilder

The current IQueryBuilder instance.

Remarks

Known issues: CROSS_JOIN is also emitted with ON, which standard SQL does not allow for a cross join. SELF_JOIN is emitted as SELF JOIN, which is not an SQL join type: PostgreSQL and MySQL read SELF as an alias for the FROM table, so the query fails when the condition names the FROM table and otherwise runs as a plain inner join. FULL_JOIN does not exist in MySQL, which reads the text as an alias plus a plain join, or fails.

ArgumentOutOfRangeException

Thrown when type is not a defined value.
