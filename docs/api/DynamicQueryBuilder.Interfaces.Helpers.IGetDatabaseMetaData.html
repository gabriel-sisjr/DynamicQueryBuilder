GetDatabaseTablesMetaDataAsync()

Get the metadata of the database tables.

Task<Dictionary<string, Dictionary<string, List<DatabaseTablesMetaData>>>> GetDatabaseTablesMetaDataAsync()

Returns

Task<Dictionary<string, Dictionary<string, List<DatabaseTablesMetaData>>>>

A dictionary keyed by schema name. Each value is keyed by table name and holds one DatabaseTablesMetaData per row of the catalog query.

Remarks

Each call opens a connection with the configured settings and runs the catalog query of GetMetadataQuery(DatabaseDriver); nothing is cached. The schemas pg_catalog and information_schema (PostgreSQL) or mysql, information_schema and performance_schema (MySQL) are excluded. Names are returned as the database reports them. This schema, table and columns shape is not the table-to-column-names dictionary that Setup(Dictionary<string, List<string>>) expects.

Exceptions

InvalidOperationException

Thrown when unable to create a command.

ArgumentException

Thrown when the connection string is null, empty or whitespace, or by the driver when it is malformed.

NotSupportedException

Thrown when the configured driver is not supported.

DbException

Thrown, as the driver's subtype (NpgsqlException or MySqlException), when connecting or running the catalog query fails. With MYSQL the query currently always fails with a MySqlException.
